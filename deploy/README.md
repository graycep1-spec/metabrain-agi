# Две версии MetaBrain: локальная и веб на VPS

Один код и одни контракты, две разные сборки. Локальная — для разработки и показа на машине; веб — для внешних пользователей на VPS. Третья, «коробка в контуре заказчика», остаётся OPEN-06: тот же код, локальная модель, отдельная поставка.

| | Локальная | Веб на VPS |
|---|---|---|
| **Зачем** | разработка, тесты, показ на рабочей машине | боевой/демо-стенд для внешних пользователей |
| **Запуск** | `docker compose up --build` (`docker-compose.yml`); или `install.ps1` / `install.sh` на рабочей станции | `/opt/metabrain`, `deploy/compose.yml`, `install.sh update` |
| **Сервисы** | `harness`, `web`, `validator`, `metabrain`, `metabrain-mcp`, `demo-landscape`, `postgres`, `qdrant`, `nats` | `web`, `harness`, `validator`, `metabrain`, `metabrain-mcp`, `demo-landscape`, `postgres` |
| **Публикация** | только `127.0.0.1`: harness 8080, web 8081, MCP 8082 | только web на `127.0.0.1:8081`, наружу — nginx + HTTPS; остальные сервисы во внутренней сети |
| **Вход** | тестовый OIDC; Telegram Login требует HTTPS | Telegram OIDC, Allowed URL `https://<домен>/auth/callback` |
| **LLM** | DeepSeek или локальный endpoint; в тестах — фейковый провайдер | DeepSeek (или локальный endpoint), DLP и бюджет включены |
| **Секреты** | `.env` из `.env.example` или `python -m src.common.demo_env` | `/opt/metabrain/deploy/.env`, права 600 |
| **Данные** | свой том `pgdata` проекта разработки | свой том `metabrain_pgdata` проекта `metabrain` |
| **MCP** | есть, слушает `127.0.0.1:8082` | есть внутри сети, без публикации порта; доступ — SSH-туннель или HTTPS-путь по решению |
| **Qdrant/NATS** | подняты как заглушки, код пока не использует | не ставятся: код пока не использует (OPEN-14, T-16) |
| **Статус** | dev/demo | MVP; сейчас localhost-only, домен и OIDC в работе |

## Что это значит на практике

- **Не переносить `.env` между версиями.** У локальной и веб-версии разные адреса, ключи бота и БД. Секреты живут только в своём окружении.
- **Не публиковать локальные порты наружу.** Локальная версия — не production: вход через Telegram на `http://localhost` не настроен, TLS нет.
- **Веб-версия не мешает соседям по серверу.** Рядом могут работать другие сервисы; у MetaBrain свой compose-проект, сеть, том и контейнер `metabrain-postgres-1`.
- **MCP есть в обеих версиях, но наружу не смотрит.** В веб-версии он доступен только внутри сети проекта; способ доступа (SSH-туннель или nginx) — отдельное решение.
- **Qdrant и NATS — только локальные заглушки.** В веб-сборке их нет, пока код их не использует.
