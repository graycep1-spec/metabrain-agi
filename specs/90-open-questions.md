# Открытые вопросы

Что не решено ни автором идеи, ни командой. Кодинг-сессия не закрывает эти пункты своими решениями: реализует точку расширения и помечает `OPEN-xx` в коде.

| ID | Вопрос | Что сейчас в спеках | Кто решает |
|---|---|---|---|
| OPEN-01 | Первый бизнес-процесс и домен демо-ландшафта | **Частично закрыт.** Команда выбрала обработку заявок/заказов (ADR-009, `60-demo-landscape.md`); подтверждение автора идеи запрошено | автор идеи |
| OPEN-02 | Воспроизводит ли двойник стиль и решения конкретного человека, а не только обязанности роли | В MVP — только обязанности и цели роли | автор идеи |
| OPEN-03 | Кто создаёт компанию и приглашает людей | **Закрыт:** ADR-010, инвайт-ссылка (C-1) | — |
| OPEN-04 | Пороги повышения автономии | **Закрыт стартовыми значениями:** ADR-011 (C-5 policy); калибровка — по данным пилота | команда |
| OPEN-05 | Голосовой канал и голосовой онбординг роли («наговорить роль») | В MVP роль описывается текстом в Telegram или в кабинете; веб-кабинет решён (ADR-012) | команда |
| OPEN-06 | Режим «коробка в контуре заказчика» с локальной моделью | Контракты не зависят от размещения; MVP — VPS + DeepSeek | команда |
| OPEN-07 | Цена, бизнес-метрики, экономика | — | автор идеи + финдиректор |
| OPEN-08 | Взаимодействие ЦС между собой (передача работы, согласование) внутри харнесса и между харнессами | Не входит в MVP | автор идеи |
| OPEN-09 | Векторное хранилище: Qdrant или pgvector | **Закрыт:** Qdrant выбран для MVP (ADR-013); `harness_id` фильтруется на стороне сервиса | — |
| OPEN-10 | Куратор ≠ владелец харнесса (передача кураторства, руководитель как куратор) | В MVP куратор = владелец | команда |
| OPEN-12 | Изоляция sandbox адаптера в целевом MVP: контейнер без сети на прогон, gVisor или иное | Демо-срез: отдельный процесс + audit-hook + статический разбор (ADR-017) | команда |
| OPEN-13 | Значения лимитов токенов, бюджета и действий (R-12) | **Закрыт для демо:** 5 $ на установку, 1 $/сутки на харнесс, 0,5 $/сутки на ЦС (ADR-021). Лимит действий и значения для пилота — открыты | команда + финдиректор |
| OPEN-14 | Провайдер эмбеддингов для векторного ретривала (у DeepSeek эмбеддингов нет) | Демо-срез: полнотекстовый поиск в Postgres; Qdrant ждёт провайдера | команда |
| OPEN-15 | «Другое семейство» модели для критика: второй вендор | Демо-срез: критик — `deepseek-v4-pro`, остальные роли — `deepseek-flash` (V4.1), один вендор (ADR-021) | команда |
| OPEN-16 | Авторизация MCP по OAuth 2.1 (спецификация MCP) вместо статических токенов клиентов | MVP: bearer-токены из секрета `MCP_CLIENTS` (ADR-022) | команда |
| OPEN-17 | Драфт адаптера моделью (разработчик роя) для систем без `/schema` | Демо-срез: шаблонный генератор для систем со схемой (ADR-023) | команда |
| OPEN-11 | Лимит числа ЦС на харнесс | Параметр policy `max_employees`, значение не задано | команда |
| OPEN-18 | Доступ к дистрибутивам и лендингу (T-36): публично или по приглашению — репозиторий приватный; где хостить страницу и архивы (сервер кабинета, GitHub Pages, отдельный хостинг) | Сейчас — `git clone` для команды и `install.sh` / `install.ps1` из рабочей копии | автор идеи + команда |
