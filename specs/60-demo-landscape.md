# Демо-ландшафт: обработка заявок и заказов

Процесс для демо и E2E-тестов (ADR-009). Выбран командой, автор идеи его ещё не подтвердил. Если процесс сменится, меняется только этот файл и фикстура; контракты C-1…C-6 не зависят от процесса.

## Сервис `demo-landscape`

Один контейнер, три учебные системы с REST API, тестовыми данными и шиной событий. Боевых данных нет.

| Система | Объекты | Поля |
|---|---|---|
| `crm` | заявка клиента | `order_id, client, items[{sku, qty}], deadline, status (new · in_work · quoted · won · lost), manager, quote?` |
| `stock` | позиция склада | `sku, title, qty_available, lead_time_days, analogs[]` |
| `pricing` | цена | `sku, cost, list_price, min_margin` |

Поля `client` и контакты клиента размечены `sensitivity: pii` (C-3 `Facts`) — их режет DLP (C-2).

События (R-17, целевой MVP): `landscape.<harness_id>.crm.order_created`, `landscape.<harness_id>.stock.qty_changed`.

Классы действий (C-3 `writes[]`, целевой MVP; в демо — только L0):

| Класс | Что делает | Обратимо |
|---|---|---|
| `crm.order.set_status` | меняет статус заявки | да |
| `crm.order.attach_quote` | прикрепляет КП к заявке | да |
| `stock.reserve` | резервирует позиции под заявку | да (снять резерв) |

## API (только чтение в демо-срезе)

HTTP JSON внутри сети compose, наружу не публикуется. Каждая система живёт под своим префиксом и сама описывает свою схему: Исследователь строит карту по `schema`, а не по знанию фикстуры.

```
GET /healthz
GET /{system}/schema            -> {system, objects[]: {name, key, path, fields[], sensitivity{field: label}, links[]: {field, to: "<system>.<object>.<field>"}}}
                                   # path — путь коллекции объекта внутри системы, например /orders
GET /crm/orders?status=         -> {items[]: Order}          # только заявки менеджера, которому выдан токен
GET /crm/orders/{order_id}      -> Order
GET /stock/items                -> {items[]: StockItem}
GET /stock/items/{sku}          -> StockItem
GET /pricing/prices             -> {items[]: Price}
GET /pricing/prices/{sku}       -> Price
```

- **Доступ:** `Authorization: Bearer <token>`. Токен выдан конкретному менеджеру и перечисляет системы, к которым у него есть доступ. Таблица токенов приходит из secret store (`env:DEMO_LANDSCAPE_TOKENS`, JSON `{token: {user, systems[]}}`) и никогда не попадает в фикстуру или ответы. Нет токена или он неизвестен → `401`; система не входит в токен → `403`; таблица токенов не настроена → `503` (при этом `/healthz` отвечает).
- **Изоляция:** `crm` отдаёт менеджеру только его заявки (`manager` = `user` токена); чужая заявка по id → `404`. `stock` и `pricing` общие.
- **Только чтение:** любой метод, кроме `GET`, → `405`. Классы записи и события — целевой MVP (T-25, R-17).
- **Время фикстуры:** «сегодня» = `2026-10-20`, от него считаются сроки поставки.

## Люди и ЦС в демо

- **Человек A** — менеджер по продажам. Его двойник: принимает новые заявки, проверяет наличие и сроки, считает цену в пределах маржи, готовит черновик КП.
- **Человек B** — второй менеджер той же компании, двойник с той же ролью.

Пример паспорта двойника A (C-6):
- обязанности: разбор новых заявок; проверка наличия и сроков; черновик КП;
- цели: КП по новой заявке готово за ≤ 2 ч рабочего времени; маржа КП ≥ `min_margin`; срок поставки ≤ `deadline`;
- границы: может предлагать аналоги из `analogs[]`; не может давать скидку ниже `min_margin`;
- эскалация: позиции нет и нет аналога; срок не укладывается в дедлайн → вопрос куратору;
- триггер демо: `schedule` каждые 15 минут, обход заявок в статусе `new`.

## Данные для сценария навыка

Фикстура содержит две похожие заявки, у которых одной позиции не хватает на складе, но есть аналог:
1. Заявка 1 менеджера A. Двойник A предлагает КП с аналогом. Куратор A подтверждает рекомендацию и правило «при нехватке позиции предлагать аналог из `analogs[]`, если маржа ≥ `min_margin`». Правило становится кандидатом навыка, проходит профиль Skill и публикуется в компанию с согласия A.
2. Заявка 2 менеджера B. Двойник B решает её с навыком компании: `skill_id@version` есть в трейсе и `sources[]`, вопроса куратору про аналог нет.
