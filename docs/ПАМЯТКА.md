# MetaBrain за одну страницу — памятка менеджеру

**Что это.** Ваш цифровой двойник — помощник в вашей роли. Он разбирает заявки, проверяет данные в системах компании и готовит черновики. Он **советует — решаете вы**. Полное руководство — `GUIDE.md`.

**Как начать (10 минут)**
1. Боту компании в Telegram: `/start` → «Согласен».
2. `/role Я менеджер по продажам, готовлю КП по новым заявкам` → войдите в кабинет через Telegram → проверьте паспорт двойника и подтвердите.
3. `/connect crm` → по ссылке введите доступ к системе в кабинете → подтвердите подключение. Так же для остальных систем.

**Каждый день**
- Двойник сам присылает разбор по расписанию — с источниками по каждому пункту.
- Спросите его: «Что с заявкой 1042?» — ответит из подключённых систем.
- Его рекомендации ждут вас в кабинете, экран «Предложения»: «Подтвердить» или «Вернуть» (можно кнопками прямо в Telegram).
- Удачное правило станет навыком; поделиться им с коллегами — по вашему согласию.

**Что гарантировано**
- Ответ — всегда с источниками; без подтверждения источниками ответ не выдаётся.
- Двойник ничего не меняет в системах без вашего разрешения; на старте — только чтение.
- Ваши данные видите только вы; персональные данные клиентов не уходят во внешнюю модель.

**Если что-то не так**
- Бот молчит на вопрос → проверьте, подключены ли нужные системы; возможно, исчерпан дневной лимит.
- «Не удалось подтвердить» → нет данных по вопросу.
- Навык не делится с компанией → в нём остались имена/номера, он остаётся личным.

Вопросы по установке и доступам — к ИТ-администратору компании.
