MetaBrain

Фабрика цифровых сотрудников. У каждого человека в компании — свой цифровой двойник роли и новые сотрудники; они работают по расписанию и на вопросы, отвечают с источниками, а действуют в системах только с разрешения человека.

Страница — черновик. Репозиторий и адрес публикации ещё не выбраны (вопрос OPEN-18), поэтому в командах ниже <страница> — заполнится при публикации. Пока команды загрузки не работают; поставить можно из рабочей копии (см. «Для команды разработки»).

Что нужно заранее

DockerDocker Engine + Compose v2 (Linux) или Docker Desktop (Windows, macOS). Больше на хосте ничего не требуется.
Ключ DeepSeekДля работы цифровых сотрудников. Расход ограничен политикой: демо укладывается в единицы центов.
Отдельный бот TelegramСоздайте в @BotFather новый бот (не используйте бот другого сервиса) — нужны токен и username.
Домен с HTTPSТолько для входа в кабинет через Telegram. Нужен на сервере; на рабочей станции кабинет открывается на localhost без входа через Telegram.

Установка

Одна команда. Установщик соберёт образ, сгенерирует ключи и пароли, спросит ключ DeepSeek и токен бота (скрытым вводом), поднимет сервисы и проверит ключи. Повторный запуск — обновление: данные и настройки сохраняются.

Linux (сервер)

curl -fsSL https://<страница>/get.sh | METABRAIN_BASE=https://<страница> bash

С HTTPS для кабинета сразу: после распаковки запустите sudo ./install.sh --domain кабинет.пример.ру --email вы@пример.ру (нужны nginx и certbot).

macOS

curl -fsSL https://<страница>/get.sh | METABRAIN_BASE=https://<страница> bash

Ставится в ~/metabrain, кабинет — на http://localhost:8081.

Windows (PowerShell)

$env:METABRAIN_BASE='https://<страница>'; irm https://<страница>/get.ps1 | iex

Нужен запущенный Docker Desktop. Кабинет — на http://localhost:8081.

Для команды разработки

git clone <репозиторий> metabrain
cd metabrain
./install.sh            # Linux, macOS
# .\install.ps1         # Windows

Загрузчик скачивает архив релиза, сверяет его контрольную сумму SHA-256 и только потом запускает установщик; подменённый архив не пройдёт проверку.

Первые шаги

  1. Напишите боту /start и подтвердите согласие — создаётся ваша компания и приходит ссылка-приглашение для коллег.
  2. Опишите роль: /role Я менеджер по продажам, готовлю КП. Войдите в кабинет, проверьте черновик паспорта двойника и подтвердите.
  3. Подключите свои системы: доступ вводится в кабинете, уходит в зашифрованное хранилище и подтверждается вами.
  4. Двойник присылает разбор с источниками; подтверждённое правило становится навыком и — с вашего согласия — переходит к коллегам.

Токены демо-систем для шага 3: <каталог>/install.sh tokens. Подробный сценарий — в файле DEMO.md в репозитории.

Если что-то не так

503 форма доступане задан ключ хранилища — install.sh configure
503 вход в кабинетнет адреса с HTTPS или данных входа Telegram
Бот молчит на вопросне задан ключ DeepSeek, либо исчерпан дневной лимит расходов
Навык не публикуетсяв навык попали имена клиентов или номера — такой навык остаётся личным
