# Слой 1 — харнесс (на человека)

Канал и API (C-1, Telegram), куратор-гейт и согласия, runtime работ и цифровые сотрудники (C-6): служебный Исследователь (C-3 discovery + драфт адаптеров), двойник и новые ЦС со скрытым роем (аналитик/разработчик/критик). LLM — через C-2. Реализация — по `specs/50-tasks.md` M2, M4, M5, M7.

Здесь появится: `Dockerfile`, приложение (рекоменд. FastAPI + aiogram), изоляция по `harness_id`, журнал, runtime работ, LLM-коннектор.

`PostgresBudgetLedger` из `src/harness/llm_usage.py` хранит фактические расходы/токены и атомарные резервации C-2 в таблицах `llm_usage` и `llm_budget_reservations`. Политические калькулятор и guard находятся в `src/llm/budget.py`; подключение к runtime и получение маршрутов из C-5 `policy.get` выполняется вместе с T-14. До этого реальные вызовы DeepSeek не запускать.
