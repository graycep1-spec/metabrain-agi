# Landscape — подключения, адаптеры, Исследователь (C-3, T-19)

- `registry.py` — `LANDSCAPE_SYSTEMS`: какие системы можно подключить и где их тест-стенд.
- `drafter.py` — шаблонный адаптер по `GET /schema` системы (ADR-023); проходит профиль Adapter.
- `bridge.py` — мост к живой системе: харнесс выполняет только `GET` в пределах `base_url` со своим токеном.
- `service.py` — `ResearcherService`: согласие на `connect` → драфт адаптера → валидатор → предложение `adapter`; согласие на `adapter` → проверка ScoreCard → активация → `discover()` через мост → карта ландшафта и журнал; затем предложения новых версий паспортов (C-6).

Адаптер исполняется общим раннером `src/common/adapter_runner.py` (тот же, что sandbox валидатора): без сети, секретов и записи.
