# SEED · golden для C-2 (LLM-коннектор) — написать первыми (красные)

Эти кейсы кодинг-сессия превращает в исполняемые тесты (pytest) до реализации коннектора:

- **GT-c2-01** chat.completions к DeepSeek (base_url из конфига) возвращает ответ OpenAI-совместимой формы.
- **GT-c2-02** подмена `LLM_PROVIDER=local` → тот же код агента работает с локальным endpoint (R-06).
- **GT-c2-03** поле, помеченное как чувствительное, НЕ уходит во внешний провайдер при `DLP_ENABLED=true` (R-07).
- **GT-c2-04** после вызова записаны provenance/стоимость/латентность на харнесс и ЦС (C-009).
- **GT-c2-05** `api_key` отсутствует в логах и в объекте запроса, сериализуемом в трейс (C-004).
- **GT-c2-06** роутер даёт критику и разработчику модели разных `family`; превышение бюджета из policy → отказ `budget_exceeded` до вызова (R-12).

Golden-наборы для C-1, C-3…C-6 перечислены таблицами в самих контрактах (`specs/30-contracts/`).
